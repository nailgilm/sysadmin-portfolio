# Портфолио системного администратора

Персональная страница Наиля: опыт, навыки и реализованные инфраструктурные проекты.

В портфолио описаны работа с Linux и Windows, сетями MikroTik/OpenWrt, Docker, Nginx, PowerShell, управление ИИ-агентами, развёртывание локального ИИ на Ollama и автоматизация публикации школьного расписания.

## Подтверждённый стек локального ИИ

- Ollama в Docker Compose на Debian 13;
- локальная модель Qwen2.5-Coder 3B;
- постоянное хранилище моделей в Docker volume;
- ограничения контейнера: 4 CPU и 6 ГБ RAM;
- API доступен только через `127.0.0.1:11434`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер.
